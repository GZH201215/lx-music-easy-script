# 第一部分 · 项目定义

## 一句话定位

> 一个漂浮在任意网页上的 LX Music 遥控器。

## 它是什么

一个油猴脚本。装进浏览器后，任何网页右上角都会出现一个洛雪音乐标志的小圆球。点一下，弹出一个小面板，让你不切出当前页面就能看到、控制你桌面上的 LX Music。

## 它解决什么问题

你正在浏览网页、看文章、查资料，突然想切歌、看歌词、暂停一下。以前要切回桌面、找到 LX Music、点一下、再切回来。现在只需要动一下网页右上角那个球。

## 它的四个核心能力

**看** —— 当前在放什么、放到哪了、歌词是什么。

**控** —— 播放暂停、上下首、拖进度、调音量、收藏、播放模式。

**搜** —— 在网页里搜歌，列出结果，用户自己选。

**进** —— 打开收藏夹、喜欢的歌手、歌单、播放列表。

## 它不该是什么

不是播放器，不自己出声。不是音源，不碰音乐资源。不是官方，不冒充、不混淆。不是大而全，够用就好。

# 第三部分 · UI 实况（基于截图）

## 悬浮球

圆形，洛雪绿，白色音符图标，外圈白环。当前用音符而非官方标志，视觉更通用，但和“LX Music 标志”定位有出入。状态指示存在但截图中未明确显示。

## 主面板

**头部区**：封面缩略图、歌名、歌手 + 专辑、右上角状态点。

**歌词区**：单行歌词，有翻译。当前不支持展开。

**进度区**：当前时间、可拖动进度条、总时长。

**控制区**：上一首、大号绿色播放/暂停圆钮、下一首、收藏心形。

**音量区**：喇叭图标、可拖动音量条、数值显示（18 即 18%）。静音点击喇叭切换，可用。

**搜索区**：当前是输入框 + 放大镜。占位符写了“歌名 或 歌名 - 歌手”，降低了学习成本。但搜完自动播放，不列结果。

**状态区**：显示“已连接 127.0.0.1:23330”、重试按钮、齿轮设置按钮。

**设置区**：内嵌在主面板底部，只有端口输入框和“保存并重连”按钮。

# 第五部分 · API 调用清单

## 5.1 HTTP 开放 API

**基础信息**：默认 `http://127.0.0.1:23330`。启用方式：设置 → 开放 API。最低 v2.7.0，跨域需 v2.8.0+。大部分 GET。

### 状态与歌词

| 功能 | 方法 | 端点 | 参数 | 调用命令 |
|---|---|---|---|---|
| 获取播放状态 | GET | `/status` | `filter`（可选） | `http://127.0.0.1:23330/status` |
| 带过滤获取 | GET | `/status` | `filter=name,progress,status` | `http://127.0.0.1:23330/status?filter=name,progress,status` |
| 当前 LRC 歌词 | GET | `/lyric` | 无 | `http://127.0.0.1:23330/lyric` |
| 全部类型歌词 | GET | `/lyric-all` | 无 | `http://127.0.0.1:23330/lyric-all` |
| 订阅状态 | GET | `/subscribe-player-status` | 无（SSE） | `http://127.0.0.1:23330/subscribe-player-status` |

**概念**：`/status` 是脚本的心跳，回答“在放什么、放到哪、什么状态”。`filter` 让你只要关心的字段。`/lyric` 给当前行，`/lyric-all` 给所有类型（原文、翻译、罗马音）。SSE 是官方推荐的实时通道，状态一变主动推，不用反复问。代价是复杂，油猴环境能否稳定用需实测。撑不住就退回轮询。

### 播放控制

| 功能 | 方法 | 端点 | 参数 | 调用命令 |
|---|---|---|---|---|
| 播放 | GET | `/play` | 无 | `http://127.0.0.1:23330/play` |
| 暂停 | GET | `/pause` | 无 | `http://127.0.0.1:23330/pause` |
| 下一首 | GET | `/skip-next` | 无 | `http://127.0.0.1:23330/skip-next` |
| 上一首 | GET | `/skip-prev` | 无 | `http://127.0.0.1:23330/skip-prev` |
| 跳转进度 | GET | `/seek` | `offset`（秒） | `http://127.0.0.1:23330/seek?offset=30` |
| 设置音量 | GET | `/volume` | `volume`（0-100） | `http://127.0.0.1:23330/volume?volume=50` |
| 设置静音 | GET | `/mute` | `mute`（true/false） | `http://127.0.0.1:23330/mute?mute=true` |
| 收藏 | GET | `/collect` | 无 | `http://127.0.0.1:23330/collect` |
| 取消收藏 | GET | `/uncollect` | 无 | `http://127.0.0.1:23330/uncollect` |

**概念**：`/play` 和 `/pause` 是独立端点，不是切换。脚本要自己知道当前状态（从 `/status` 来）再决定发哪个。`/seek` 的 `offset` 是目标秒数，不是增量。拖动时不要每动一下都发，松手发一次。`/volume` 和 `/mute` 是一对，静音是独立开关，不影响音量值。`/collect` 和 `/uncollect` 名字相似，别发混。

## 5.2 Scheme URL

**格式**：`lxmusic://<type>/<action>/[path]/...?[param=value]&data={urlencoded_json}`

**概念**：HTTP API 只管控制和状态，不管内容发现。搜索、打开歌单、打开收藏夹这些动作发生在 LX Music 内部，HTTP 没有对应端点。Scheme URL 是浏览器和客户端之间的桥。风险：依赖客户端注册协议，没装或注册坏了点击没反应，脚本要给出反馈。

### data 传参（复杂场景）

| 功能 | URL 结构 | data 必要字段 |
|---|---|---|
| 播放歌单 | `lxmusic://songlist/play?data=...` | `source`、`id` 或 `url` |
| 播放歌曲 | `lxmusic://music/play?data=...` | `name`、`singer`、`source`、`songmid` |
| 搜索并播放 | `lxmusic://music/searchPlay?data=...` | `name` |

示例：`lxmusic://songlist/play?data=%7B%22source%22:%22kw%22,%22id%22:%223373919903%22%7D`

### 路径传参（简单场景）

| 功能 | URL |
|---|---|
| 搜索并播放 | `lxmusic://music/searchPlay/{歌名-歌手}` |
| 播放 | `lxmusic://player/play` |
| 暂停 | `lxmusic://player/pause` |
| 下一曲 | `lxmusic://player/skipNext` |
| 上一曲 | `lxmusic://player/skipPrev` |
| 切换播放/暂停 | `lxmusic://player/togglePlay` |
| 收藏 | `lxmusic://player/collect` |
| 取消收藏 | `lxmusic://player/uncollect` |
| 不喜欢 | `lxmusic://player/dislike` |

# 第六部分 · 交互细节

## 6.1 进度条新交互

| 编号 | 规则 | 概念 |
|---|---|---|
| PB-01 | 拖动时进度条不动 | 滑块不跟手，或只显示预览标记 |
| PB-02 | 拖动时歌词同步 | 拖到哪显示哪句歌词 |
| PB-03 | 松手才跳转 | 松手才发 `/seek` |
| PB-04 | 松手前不干扰播放 | 拖动中原播放继续，不暂停 |

**概念**：这套规则解决一个矛盾——拖动时的实时反馈 vs 播放器的稳定性。牺牲进度条的视觉跟随，换取歌词预览和播放不中断。需要补充：时间气泡（显示拖到哪）、歌词高亮预览、松手空白处取消拖动。

## 6.2 搜索收起式

| 编号 | 规则 |
|---|---|
| Q-01 | 默认只显示放大镜 |
| Q-02 | 点击展开搜索框 |
| Q-03 | 展开自动聚焦 |
| Q-04 | Esc 或点外部收起 |
| Q-05 | 结果列出候选，用户选 |
| Q-06 | 点击后自动收起 |

**概念**：解决功能入口可见性 vs 面板简洁度的矛盾。默认隐藏，点击展开。若空间紧张，搜索框从放大镜位置向下滑出，不顶开面板。

## 6.3 面板轻量原则

一切默认轻，需要时才重。面板默认收起，搜索默认藏成放大镜，歌词默认穿透。

# 第七部分 · 稳定性

## 连接抖动抑制

**问题**：LX Music 有时抽搐，悬浮球状态一绿一灰来回闪。

**原因推测**：`/status` 偶发超时、SSE 短暂断开、播放器忙时响应慢被误判。

| 编号 | 规则 | 概念 |
|---|---|---|
| CS-01 | 断开判定加延迟 | 首次失败不算断开，等 7.5 秒 |
| CS-02 | 延迟内继续重试 | 每 1–2 秒重试 |
| CS-03 | 任意一次成功即恢复 | 不累计失败 |
| CS-04 | 状态点平滑过渡 | 加淡出动画 |
| CS-05 | 抖动抑制 | 7.5 秒内状态不变 |
| CS-06 | 真断开才提示 | 超过 7.5 秒才显示未连接 |
| CS-07 | 中间态显示 | 7.5 秒内显示“连接中” |

**概念**：7.5 秒比常见 5 秒更宽松，覆盖切歌、加载、短暂卡顿。代价是真断开时用户要等 7.5 秒才看到提示。这是取舍。

# 第八部分 · 桌面歌词

## 方案 A：页面内浮动歌词

油猴脚本无法创建真正独立窗口。采用页面内可拖动歌词浮层，从面板拖出，可收回。

| 编号 | 需求 | 概念 | 优先级 |
|---|---|---|---|
| DL-01 | 从面板拖出 | 歌词区可拖拽，拖出变独立浮层 | P0 |
| DL-02 | 独立可拖动 | 浮层可拖，位置独立记忆 | P0 |
| DL-03 | 可收回面板 | 拖回或按钮收回 | P0 |
| DL-04 | 显示翻译 | 原文 + 翻译 | P1 |
| DL-05 | 自动滚动 | 跟随播放高亮 | P1 |
| DL-06 | 透明度可调 | 0.4–1.0 | P2 |
| DL-07 | 字号可调 | 小/中/大 | P2 |
| DL-08 | 锁定位置 | 防误拖 | P2 |
| DL-09 | 随页面切换保持 | 换页面位置状态不变 | P0 |
| DL-10 | 可关闭 | 回到面板内 | P0 |
| DL-11 | 默认穿透 | 歌词文字 `pointer-events: none` | P0 |
| DL-12 | 把手可拖 | 悬停显示拖动把手 | P0 |
| DL-13 | 按钮可点 | 关闭、锁定、收回 | P0 |
| DL-14 | 交互模式 | 按 `Alt` 或长按临时全交互 | P1 |
| DL-15 | 不拦截页面 | 任何情况不挡页面点击 | P0 |

## 点击穿透

**核心矛盾**：浮层要显示在最上面，又要点击穿透到下面。

**方案**：分区控制，不是一刀切。

| 区域 | 视觉 | 交互 |
|---|---|---|
| 歌词文字区 | 最上层 | `pointer-events: none` |
| 拖动把手 | 显示 | `pointer-events: auto` |
| 操作按钮 | 显示 | `pointer-events: auto` |
| 浮层背景 | 半透明或透明 | `pointer-events: none` |

**两种模式**：穿透模式（默认，全穿透）和交互模式（按 `Alt` 临时全交互，可选中复制）。

**拖动把手**：平时隐藏，悬停时左侧出现小圆点。

**概念**：歌词是给眼睛看的，不是给鼠标点的。只有需要操作浮层本身时，才临时变成可交互。和面板、搜索一样，一切默认轻。

## 需要想清楚

穿透模式下歌词不能选中，要选中进交互模式。浮层和悬浮球重叠时悬浮球优先。拖到边缘限制视口内。全屏视频时可能被盖住，浏览器限制无法突破。

# 第九部分 · 跨页面位置一致性

## 需求

切换页面时，悬浮球、面板、歌词浮层位置不变。

## 技术现实

油猴脚本每页重新注入，所谓“保持”实际是每次重建时从存储读位置重新放。

## 存储清单

| 编号 | 项目 | 存储键 |
|---|---|---|
| PS-01 | 悬浮球位置 | `lxmes:ball-pos` |
| PS-02 | 面板展开状态 | `lxmes:panel-open` |
| PS-03 | 面板位置 | `lxmes:panel-pos` |
| PS-04 | 歌词浮层位置 | `lxmes:lyric-pos` |
| PS-05 | 歌词浮层开关 | `lxmes:lyric-detached` |
| PS-06 | 歌词浮层透明度 | `lxmes:lyric-opacity` |
| PS-07 | 歌词浮层字号 | `lxmes:lyric-font-size` |
| PS-08 | 歌词浮层锁定 | `lxmes:lyric-locked` |

## 恢复逻辑

| 编号 | 规则 |
|---|---|
| PS-09 | 页面加载时读存储 |
| PS-10 | 位置越界回退默认 |
| PS-11 | 多屏适配需重新校准 |
| PS-12 | 首次用默认值 |
| PS-13 | 拖动松手时写，不每次移动都写 |

**概念**：内存换页面就没了，跨页面必须 `GM_setValue` 持久化。内存只是缓存，存储才是真相。

# 第十二部分 · 判断标准

装上去之后，你会不会真的用它。

如果它变成你浏览器里一个安静但顺手的东西，就成了。

三个方向：**连接不抖** → 它看起来是稳的。**歌词能拖出来** → 它能脱离面板独立存在。**位置跨页面保持** → 它一直在那，不随页面刷新消失。

一切默认轻，需要时才重。
